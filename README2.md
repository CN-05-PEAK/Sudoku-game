# Pro Sudoku Master 🧩
[Play the Live Game Here](https://CN-05-PEAK.github.io/sudoku-game/)

A clean, interactive Sudoku game built entirely with HTML, CSS, and Vanilla JavaScript. This project demonstrates DOM manipulation, state management, and algorithmic problem-solving.

## ✨ Features
* **Algorithmic Generation:** Uses a backtracking algorithm to dynamically generate unique, solvable boards on the fly.
* **Multiple Difficulties:** Select between Easy, Medium, and Hard modes, which dynamically adjust the number of pre-filled cells.
* **Smart Highlighting:** Automatically highlights the active row, column, 3x3 sub-grid, and all matching numbers across the board to assist with gameplay.
* **Advanced Gameplay Controls:** Features an Undo/Redo stack, a Hint system, and a dedicated Note-taking mode for pencil marks.
* **Modern UX/UI:** Fully responsive design for both desktop and mobile screens, complete with a Light/Dark theme toggle.
* **Keyboard Support:** Full keyboard navigation using arrow keys, numbers for input, backspace to clear, and 'n' to toggle notes.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure.
* **CSS3:** Custom CSS variables for theming, Grid/Flexbox for layout, and responsive media queries.
* **Vanilla JavaScript (ES6+):** Core game logic, backtracking algorithm, and event handling.

## 🚀 How to Run Locally
Since this is a single-file application, running it locally is incredibly simple:
1. Clone the repository: `git clone https://github.com/yourusername/sudoku-game.git`
2. Open the `index.html` file directly in any modern web browser.
